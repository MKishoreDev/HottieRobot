```
Deploying on Local Machine
```

</p>

```console
~$ git clone https://github.com/MKishoreDev/HottieRobot
~$ cd HottieRobot
~$ cp sample_config.py config.py
```

Edit `config.py` with your own values.

Start with:

```console
python -m Hottie_Robot
```
